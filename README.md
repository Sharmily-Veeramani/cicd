
# CI/CD Pipeline Implementation

## Project Name
CI/CD Pipeline using GitHub Actions, Tekton and OpenShift

## Description
This project demonstrates automated Continuous Integration and Continuous Deployment using GitHub Actions and OpenShift Pipelines.

## Technologies
- Python
- Flask
- GitHub Actions
- Flake8
- Nose
- Tekton
- OpenShift

## Features
- Automated code linting
- Automated unit testing
- Tekton task execution
- OpenShift application deployment
- Application monitoring and logs

## Objective
To automate application testing, integration and deployment through a CI/CD pipeline.
